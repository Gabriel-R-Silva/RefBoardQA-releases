# RefPad

An infinite, local-first board for Windows to collect screenshots, notes and annotations as visual evidence. Built for QA and systems analysts.

**[Download the latest version](../../releases/latest)** — run `RefPad-Setup-X.Y.Z.exe` (per-user install, no administrator needed, .NET not required). Verify it against `checksums.txt` if you like.

- This repository only hosts the installers (`.exe`) and `checksums.txt` of each release, generated by the CI/CD pipeline, so the app can check for updates by itself.
- The source code is maintained in a private repository.
