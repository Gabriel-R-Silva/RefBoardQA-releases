# RefBoardQA — Releases

Este repositório existe apenas para hospedar os instaladores do **RefBoardQA** e permitir que o
próprio aplicativo verifique automaticamente se há uma versão nova disponível.

- O código-fonte do RefBoardQA é mantido em um repositório privado.
- Nenhum código-fonte é publicado aqui — apenas os instaladores (`.exe`) e `checksums.txt` de
  cada release, gerados automaticamente pelo pipeline de CI/CD.
- Para baixar a versão mais recente, veja a aba [Releases](../../releases).
